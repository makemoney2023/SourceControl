## Executive summary

This playbook defines how Blacksage Kennels **closes** qualified kennel inquiries and **retains** placed puppy families — aligned to D2 trust-first positioning, Package A/B/C packaging, and Phase 6 GTM locks. The site earns informed inquiry; everything after form submission is operator-owned conversation: **qualify → price discuss (off-site) → deposit (if waitlisted, off-site) → contract → placement → go-home CS**.

**Three playbook parts:**

| Part | Scope | Owner |
|------|-------|-------|
| **I — Close** | Qualification gates, talk tracks, objections, deposit/placement conversations | Operator + sales enablement |
| **II — Respond** | Inbound triage, SLAs, auto-replies, follow-up sequences | Operator (Q7) |
| **III — Retain** | Go-home transition, puppy support, escalation, referral loop, alumni | Operator CS |

**Hard constraints:** No on-site prices or payment. No FOMO or high-pressure tactics. Anti-persona filtered early and respectfully. All Blacksage-specific SLA numbers, price bands, and deposit amounts are **[Operator to set]** until Q7/OP-P1/OP-P2 are closed.

# Part I — Close (qualification, talk tracks, objections, deposit/placement)

## 1. Qualification checklist

Use at each package transition. Document pass/fail in operator CRM or inquiry log. **Form submission alone does not satisfy any gate.**

### 1.1 Gate: Inquiry → Package A (Interest list)

**When:** Tier 1 default; buyer not yet ready for waitlist.

| # | Criterion | Pass signal | Fail / hold |
|---|-----------|-------------|-------------|
| A1 | Site engagement | References Health/Education, Dogs, or About; thoughtful message (50+ chars) | One-line "how much?" only → anti-persona screen |
| A2 | Intent clarity | Companion / family / sport-working / show-structure goal stated | Vague goals → follow-up before confirming A |
| A3 | Timeline realism | Timeline field completed; accepts inquiry ≠ reservation | "Need puppy this month" without flexibility → impulse screen |
| A4 | Experience baseline | Prior Rottweiler experience field completed | No experience OK if education appetite shown |
| A5 | Anti-persona screen | No guard-dog, protection, or aggression language | Guard-dog fantasy → disqualify (§1.4) |
| A6 | Contact validity | Valid email; region provided | Spam / honeypot → no action |
| A7 | Consent | "I understand inquiry is not a reservation…" checked | Missing → request resubmission |

**Outcome:** Add to interest list; send confirmation (§2.2). **No price. No deposit.**

### 1.2 Gate: Package A → Package B (Waitlist consideration)

**When:** Q1 = active program; waitlist capacity open; B1–B9 pass.

| # | Criterion | Pass signal | Fail / remain on A |
|---|-----------|-------------|---------------------|
| B1 | Program maturity | Q1 active; waitlist open | Pre-litter → stay on A |
| B2 | Research depth | Reviewed site proof; can articulate why Blacksage | Price-only → remain A or decline |
| B3 | Home fit | Household context supports Rottweiler ownership | Red flags → hold or decline |
| B4 | Activity match | Goals align with program (companion/family/sport — not guard) | Guard intent → disqualify |
| B5 | Temperament expectations | Accepts ADRK bounds: biddable, even-tempered | Machismo framing → disqualify |
| B6 | Waitlist acceptance | Accepts category wait norm (**Assumption:** 6–12+ months) | Impulse timeline → remain A or decline |
| B7 | Reference (optional) | Trainer/vet reference if asked | — |
| B8 | Extended fields | Package B form complete + agreement acknowledgment | Incomplete → request before upgrade |
| B9 | Phone/video screen | Operator conversation completed — **[Operator to set]** | Form-only → do not upgrade to B |

**Outcome:** Waitlist consideration confirmed. **No price on first contact unless buyer asks after B1–B9 pass.** Deposit only after explicit B approval (§3).

### 1.3 Gate: Package B → Package C (Placement)

**When:** Litter match; contract ready; mutual fit reconfirmed.

| # | Criterion | Pass signal | Fail / remain on B |
|---|-----------|-------------|---------------------|
| C1 | Waitlist standing | Approved member in good standing | Never approved → cannot reach C |
| C2 | Litter match | Assignment aligns with preferences and program plan | No match → remain B |
| C3 | Reconfirm fit | Home/activity still suitable since B approval | Life change → re-screen |
| C4 | Contract review | Buyer received contract/guarantee/return policy | Unsigned → no C |
| C5 | Price discussion complete | Investment discussed off-site; buyer accepts in principle | Unresolved → remain B or release |
| C6 | Deposit terms accepted | Written terms provided and accepted — **no amounts in scripts** | Hesitation → address trust, not pressure |
| C7 | Pickup/logistics | Geography and handoff confirmed when Q2 set | Mismatch → hold |
| C8 | Operator sign-off | Operator explicitly approves placement | No approval → never C |

**Outcome:** Signed contract; deposit collected off-site; placement scheduled. **Never confirm placement in auto-reply or before C8.**

### 1.4 Anti-persona disqualification (all packages)

If **any** row matches strongly, do not upgrade — use polite decline (§2.6).

| Anti-persona | Signals | Action |
|--------------|---------|--------|
| **Guard-dog fantasy** | "Protection," "attack," "weapon," "intruder," aggression as desired trait | Disqualify |
| **Price-only comparator** | First/only question is price; dismisses health/pedigree | Decline or A-only, no price quote |
| **Impulse buyer** | "This weekend," "ASAP," "any puppy now" | Remain A or decline |
| **Checkout expecter** | "Pay online?" "Reserve with card?" "Add to cart?" | Clarify once; if persists, decline |

## 2. Talk tracks

Scripts are **guides**, not verbatim mandates. Maintain calm, evidence-led voice throughout.

### 2.1 Initial inquiry response (email)

**Subject:** Your Blacksage Kennels inquiry — next steps

> Thank you for taking time to review our program before reaching out. We received your inquiry and appreciate your interest in an ADRK-aligned Rottweiler placement.
>
> **What happens next:** Each inquiry is reviewed individually. This is not a reservation or automatic waitlist placement. We look for mutual fit — your home, goals, and timeline aligned with our selective placement approach.
>
> **[Operator to set]:** We aim to respond within [X business days]. If your inquiry indicates waitlist consideration, we may invite a brief phone conversation to discuss fit, our health and temperament standards, and the placement process.
>
> In the meantime, if you have not already, we encourage you to review our Health & Education section — particularly our placement process overview and health testing categories.
>
> We respect the commitment a Rottweiler represents and look forward to learning more about your household and goals.
>
> Warm regards,  
> [Operator name / Blacksage Kennels]

**Do not include:** prices, deposit amounts, "you're on the list," scarcity language, or placement confirmation.

### 2.2 Package A confirmation (interest list)

**Subject:** You're on the Blacksage interest list

> Thank you for joining our interest list. You will receive occasional updates when we have program news worth sharing — for example, when breeding stock profiles or litter plans are verified and published. We do not send weekly puppy promotions.
>
> **Please note:** Interest list membership is not a waitlist reservation and does not guarantee a puppy. When our active program opens waitlist consideration, we will contact interest list members who may be a fit.
>
> If your timeline or goals change, you may reply to this email at any time.

### 2.3 Qualification call opener (phone)

> "Thank you for making time today. I want to start by saying this conversation is a mutual fit check — not an approval interview. We place selectively because a Rottweiler is a ten-plus-year commitment, and our job is to match the right puppy to the right home.
>
> I've reviewed your inquiry. Before we go further, I'd like to hear in your words what drew you to an ADRK-aligned program and what role you see the dog playing in your household — companion, family, sport, or something else.
>
> Then I'll share how our placement process works, what health and temperament standards we hold, and honest timeline expectations. You can ask anything. If we're not the right fit, I'll say so respectfully — and I hope you'll feel comfortable doing the same."

**Do not open with:** price, deposit, litter availability, or "we have puppies ready."

### 2.4 Qualification call — core questions (Package B path)

| Topic | Sample question | Listening for |
|-------|-----------------|---------------|
| Research | "What did you learn from our site that mattered most?" | Evidence engagement vs. price-only |
| Goals | "Describe a typical week with the dog." | Realistic activity match |
| Experience | "Tell me about your Rottweiler or large-breed experience." | Openness to guidance |
| Household | "Who lives at home? Other pets? Children?" | Safety and management plan |
| Temperament | "What temperament traits matter most?" | Biddable/devoted vs. guard fantasy |
| Timeline | "Our process often involves a wait. What timeline are you working with?" | Flexibility vs. impulse |
| Commitment | "Are you prepared for health testing literacy, training, and breed responsibility?" | Seriousness |
| Referral | "How did you hear about us?" | Referrer thank-you loop (qualified only) |

**Redirect if guard-dog language appears:**

> "I want to be direct: Blacksage breeds toward the ADRK standard — good-natured, devoted, biddable, even-tempered. We do not breed or place for guard work, protection sport, or aggression marketing. If your primary goal is a protection dog, we are not the right program — and I'd rather tell you that now than waste your time."

**Subject:** Regarding your Blacksage Kennels inquiry

## 3. Objection handling

Respond with calm precision. Never pressure. Never invent numbers.

### 3.1 "How much do puppies cost?" / price-first

> "We don't publish pricing on our website — that's intentional. Investment is discussed individually after we've both determined mutual fit, typically once waitlist consideration or placement matching is underway. I'd rather understand your goals and our program first so any number we discuss comes with context about health testing, placement support, and what you're actually receiving.
>
> If price is the only decision factor, we may not be the right fit — and that's okay."

**If they refuse to engage without a number:**

> "I understand budget matters. Without a qualification conversation, I can't provide a meaningful quote tied to our program. If you'd like to proceed with that conversation, I'm happy to. If not, I respect that and won't press."

**Do not:** give a range, "starting at," or category midpoint as Blacksage policy.

### 3.2 "Why don't you list prices on the site?"

> "Serious buyers in this category typically evaluate health clearances, pedigrees, and placement philosophy before price — same as you would with other premium ethical breeders. Publishing a number without context attracts price-shoppers and impulse inquiries that aren't fair to the dogs or to families who've done the research.
>
> Our site is built for due diligence first. Pricing comes after we know we're aligned."

### 3.3 "How long is the wait?"

> "Waitlist timelines vary by program capacity and litter planning. In our category, six to twelve months or longer is common — **Assumption** from market research, not a guarantee of our current queue.
>
> **[Operator to set]:** I'll give you an honest picture of our current posture after we complete qualification. Inquiry and interest list membership don't hold a place in line — approved waitlist placement does."

**Do not:** promise a date, imply urgency, or say "spots are filling up."

### 3.4 "Why do you require a deposit?" / deposit hesitation

> "If you're approved for our waitlist, a deposit may be required — terms are provided individually in writing. Deposits in ethical breeding typically credit toward placement and reflect a shared commitment after mutual fit is established — not a fee to skip the line.
>
> We don't collect deposits at inquiry or on our website. You'll receive full terms before any payment is requested, and you'll have time to review them."

### 3.5 Guard-dog / protection requests

> "Blacksage breeds toward ADRK/FCI temperament — good-natured, devoted, biddable, even-tempered. A Rottweiler is a powerful breed, and responsible ownership includes training and management — but we do not market or place for guard work, protection roles, or aggression-forward use cases.
>
> If protection is your primary goal, I recommend working with a qualified trainer on a different path. We're not the right kennel for that intent."

**Action:** Disqualify; do not offer deterrence workarounds.

### 3.6 Impulse buyer / "Do you have puppies available now?"

> "We place selectively and plan litters deliberately — we don't operate on an 'available now' model. If you need a puppy on an immediate timeline, we likely can't serve that need well, and I'd rather be honest than rush a mismatch.
>
> You're welcome to join our interest list for future program updates, but I can't promise availability on your timeline."

### 3.7 "Can I just pay online / reserve on the website?"

> "No — and that's by design. Our website is for research and informed inquiry, not checkout. Every placement goes through qualification and contract review. That's how ethical breeders protect the dogs and the families they go to."

### 3.8 "Another breeder quoted me $X"

> "Different programs carry different health testing depth, pedigrees, placement support, and placement standards. A number alone doesn't compare those.
>
> If Blacksage is the right program for you, we'll discuss investment in context after qualification. If the deciding factor is the lowest quote, we may not be the best match — our selective model isn't built to compete on price alone."

## 4. Deposit and placement conversation guide

**Scope:** Off-site only. After Package B approval. No dollar amounts in scripts.

### 4.1 Sequencing (non-negotiable)

```
1. Qualification complete (B1–B9 pass)
2. Operator approves waitlist membership
3. Written terms sent (deposit, refund policy, placement conditions) — [Operator to set / OP-P2]
4. Buyer reviews and accepts in writing
5. Deposit collected off-site — [Operator to set payment method]
6. Waitlist position confirmed in writing — [Operator to set whether position numbers shared]
7. Litter match → reconfirm fit → contract → Package C → balance per contract
```

**Never:** collect deposit before step 3. Never collect on website. Never verbal-only deposit agreements.

### 4.2 Waitlist approval + deposit invitation

> "I'm pleased to let you know we've approved your waitlist consideration — subject to the written terms I'm sending separately.
>
> The terms cover waitlist deposit, how it credits toward placement, refund conditions, and what happens if either party needs to withdraw. Please read them fully. There is no payment due until you've accepted in writing and had your questions answered.
>
> Take the time you need. We're not running a countdown on your decision."

### 4.3 Deposit Q&A (without stating amounts)

| Buyer question | Response frame |
|----------------|----------------|
| "How much is the deposit?" | "The amount is in the written terms I'm providing — it reflects our operator policy, not a website quote." |
| "Is it refundable?" | "Refund conditions are spelled out in your terms — [Operator to set / OP-P2]. Read that section and ask me anything unclear." |
| "Does it hold my puppy?" | "It confirms waitlist commitment after approval — not a specific puppy assignment. Matching happens when a litter aligns with your profile." |
| "Can I pay in installments?" | "[Operator to set — OP-P3 payment schedule]" |
| "I need to think about it." | "Absolutely. The terms will be there when you're ready. No pressure from our side." |

### 4.4 Litter match → placement (Package C)

> "We have a potential match we'd like to discuss — a litter planned for [timeframe — operator verified only]. Before we go further, I want to reconfirm your household and goals haven't changed since waitlist approval.
>
> If we both agree to proceed, I'll send the placement contract and discuss investment balance, pickup logistics, and health documentation. Signing and deposit credit application happen after you've reviewed everything.
>
> If this litter isn't the right fit, you remain on the waitlist for a future match — no penalty for passing on a single opportunity, per your contract terms."

### 4.5 Site-legal deposit language alignment

When referencing what the **website** says (Package B form acknowledgment):

> "As our site states: a waitlist deposit may be required after application approval. Terms are provided individually."

## 15. Issue escalation paths

### Principles

1. **Respond with calm urgency** — health may be time-sensitive; temperament rarely is.
2. **Document every escalation** **[Operator to set location]**.
3. **Contract is source of truth** for return, rehoming, guarantee, health disputes.
4. **Never blame the buyer** for normal puppy behavior; never dismiss legitimate health concerns.

### Path A — Health concerns

| Severity | Examples | First responder | Action |
|----------|----------|-----------------|--------|
| **Emergency** | Collapse, severe injury, acute distress | Buyer → emergency vet **first** | CS available after stabilizing; notify operator |
| **Urgent (non-ER)** | Persistent GI, limping, not eating 24h+ | CS → operator | Encourage vet visit; follow **per operator contract** |
| **Routine** | Vaccine timing, diet question | CS | Educate; defer to buyer's vet |

**Script anchor:** "Your puppy's health comes first — please see your veterinarian. Once you have their assessment, send us [records/notes] and we'll work through next steps per our placement agreement."

### Path B — Temperament / behavior

| Signal | CS response |
|--------|-------------|
| Puppy biting, chewing, zoomies | Reassure; training resources; trainer coordination (§16) |
| Fear periods, reactivity onset | Recommend Rottweiler-experienced trainer; **no guard-dog referrals** |
| Aggression toward people/animals | Operator consult; professional eval; **per operator contract** |
| Buyer wants "protection training" | Redirect to ADRK companion/working framing; decline machismo programs |

### Path C — Rehoming / return

| Scenario | CS role | Policy reference |
|----------|---------|------------------|
| Buyer cannot keep dog | Listen without judgment; explain **per operator contract** | OP-P6 |
| Operator-assisted rehoming | Facilitate if contract allows | No public FOMO posts without operator approval |
| Health-based return dispute | Document; operator decision | **Per operator contract** |
| Buyer requests refund | Defer to contract + operator | No invented refund windows |

**Script anchor:** "We're committed to responsible placement for the life of the dog. Let's review what your agreement outlines and find the best path forward together."

### Escalation matrix

```
Owner contacts CS
  ├─ Health emergency → ER vet first → notify operator
  ├─ Health non-emergency → vet visit → records → per operator contract
  ├─ Temperament (normal puppy) → education + trainer offer
  ├─ Temperament (serious) → operator + professional eval
  └─ Rehoming / return → per operator contract → operator decision
```

## 16. Referral loop activation (post-placement only)

Inherited from Phase 6 GTM — CS executes the **owner side** after verified satisfaction.

```
Positive trigger (verified satisfaction — §13)
  → Operator 1:1 ask (not mass email)
  → Owner shares canonical site URL if willing
  → New buyer verifies on site → inquiry
  → "How did you hear about us?" → thank referrer on qualified leads only
```

### When to ask (all gates must pass)

| Gate | Requirement |
|------|-------------|
| **G1 — Timing** | Minimum **[Operator to set]** after go-home (recommend: post–month-one or later) |
| **G2 — Satisfaction** | Verified positive signal (§13) — not absence of complaints alone |
| **G3 — No open disputes** | No unresolved health, contract, or temperament escalation |
| **G4 — Owner consent** | Ask permission; accept "not now" without follow-up pressure |

### How to ask (1:1, no FOMO)

> "We're glad [dog] is doing well. If you know someone researching an ADRK-aligned Rottweiler program the way you did — health tests, temperament, selective placement — we'd appreciate you sharing our website when it feels natural. No obligation; we only ask when families tell us things are going well."

**If owner agrees to testimonial (PRD C-03 backlog):** Written consent required; publish only verified statements; photo only with explicit permission.

### Referral anti-patterns

| Never | Why |
|-------|-----|
| Referral ask before go-home or during deposit stress | Trust inversion |
| Mass "refer a friend" with incentive | No affiliate/commission v1 |
| Public pressure ("tag us or share") | Astroturf risk; damages M5 |
| Referral tied to price discount | Price-forward; not D2 |
| Fake or coached testimonials | SD5 / Tier 3 violation |
