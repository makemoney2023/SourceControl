# The Super Patch Income Stack — Visual Concept Deck

Fifteen 16:9 design-inspiration frames for the new-affiliate presentation. These are art direction references, not final slides — hand them to design as the visual language, then rebuild the type in Avenir Next / Montserrat Black.

## Art direction

- **Backgrounds:** near-black navy (#05070F) with soft radial gradients and volumetric haze
- **Accents:** electric blue, neon green, vivid orange, deep violet — one color owns each section
- **Signature:** SP Red (#DD0604) reserved for single focal moments, never as a fill
- **Type:** Montserrat Black / Avenir Next Heavy, uppercase headlines, 30–50 words per slide max
- **Recurring device:** the Full Stack Flywheel (frame 04) returns as a small corner motif on every section opener, with the active arc lit

## Notes for design

- Every dollar and percentage figure in these frames is a placeholder rendering. Re-typeset all numbers from the source compensation document before anything goes in front of an audience.
- Frames 09 and 12 carry real numbers and need a compliance read.
- Earnings figures need the income-disclosure line wherever they appear.
