## What Retain means here

Retain is **not** a daily streak, a 6-week course, or a kennel go-home.

| Word | Meaning on Telltail |
|------|---------------------|
| **Activate** | First Lite scare **finishes**: clip (or stills) → gate → **card or refuse** → stop-rule. **[F]** US-07 |
| **Retain / Keep** | They come back for a **new scare** and still accept an honest read — including a refuse. **[F]** GTM demand path |
| **Refuse-as-success** | A refuse is competence. It is the product working, not a failed session and not a refund trigger by itself. **[F]** |
| **Chat (US-21)** | Context + conversation **between** scares and **after** a refuse. Not a text-only vision read. A moment card still needs a clip. **[F]** founder lock |

Inquiry / placement / puppy go-home language from other ventures **does not apply.**

## Lite → first scare (activation)

**Activation event:** first Lite read completes (card **or** refuse). Reciprocity, not a mid-moment tease. **[F]** US-07 / BR-6

| Rule | Pass | Fail |
|------|------|------|
| First read finishes | Capture/upload → gate → card or refuse → stop-rule, no paywall in the loop | Crash, hang, or “upgrade to see the card” |
| Refuse counts | Bite-risk / kids / floor-fail refuse **is** a completed scare | Treating refuse as “the trial failed” |
| Safety on Lite | Cheap-model still refuses. Gates always on. **[F]** BR-3 | Flash-class tease on Lite; safety downgrade |
| Quota after | 3–5 Lite reads, then Plus or wait. Not silent Flash-unlimited. **[F]** AC-07.2 | Unlimited try |

**Aha moment (onboarding pack, adapted):** they saw the stop-rule on a *real* scare — not a tour of five features.

Empty state: one primary action — **film this moment** (or attach in chat). No demo-dog sticker wall.

## Chat as a retain lane (US-21)

Founder lock (mid-phase): owners may **describe the issue via chat**, not only send media. Chat is first-class. It is **not** a vision read.

| Chat may | Chat must not |
|----------|----------------|
| Take the scare story (kids / food / doorbell / visitor) | Render a refuse-first **vision card** from text alone |
| Ask them to **attach a clip or stills in the thread** | Say “I saw your dog” or diagnose from a paragraph |
| After a refuse: restated stop-rule, space now, escalate-to-human | Soften a refuse because they typed more context |
| Between scares: “film the next one,” after-action upload (US-14) | Become a daily-streak coach or anonymous PetGPT |
| Honor refuse-first, banned claims, reward-based / no-dominance, kids-in-frame, K1 | Name a trainer (A5 OPEN). Do **not** name a public expert. |

**Quota:** a vision read consumes a Lite/Plus unit when a model ran. Text-only context does **not** invent a seen-dog read. **[F]** AC-21.5 / BR-14

If live-film fails, chat + later attach is the hedge — **not** the pitch. If it dominates, re-label toward homework (closer to B). Do not keep selling “this second.” **[I]** GTM / US-14

## Refuse-as-success

Refuse is competence. Quota **cannot** skip a bite-risk / kids / low-confidence refuse. The gate **always** runs, including at **0 remaining**. A refuse **consumes** the read when a model ran. **[F]** BR-1, BR-2, US-04

| Situation | CS / chat line | Forbidden |
|-----------|----------------|-----------|
| Gate refuses | “We will not coach this. Stop. Make space. Call a pro.” | Preview of “what we would have said” |
| Owner at 0 Plus | Gate still runs. Refuse still happens. | Skip to save a credit |
| Owner wants a card anyway | Credits are not a refuse bypass. | Goodwill override on bite-risk / kids |
| Owner thinks refuse = broken | “That *is* the product. A wrong coach does not fire.” | Refund-because-refused as default |
| Freeze / whale-eye / stare | Gate **inputs**, not auto-refuse. **[F]** AC-04.1 | “We always refuse on whale eye” |

Kids-in-frame: refuse. No child identity template. Clip is not a scorable training asset. **[F]** AC-04.4

## Escalation matrix

Two directions. Do not mix them.

### A. Owner-facing — escalate-to-human (US-10)

On refuse or on a card whose stop-rule is escalate:

1. **Now:** stop. Create space. Do not coach through a bite-risk.
2. **Then:** licensed **veterinarian** / **veterinary behaviorist (DACVB)** / **CAAB** / **credentialed trainer** (reward-based).
3. Never diagnose. Never name a disease or drug. Never “relaxed / safe / won’t bite.” Never “replaces your trainer.”
4. No in-app bite-history protocol. No trainer marketplace this pass (US-18 out).

Use **DACVB / CAAB / credentialed trainer** — not a celebrity method, not an unnamed PetGPT. **A5 OPEN:** do not name a public expert.

### B. Internal (support → product / leadership)

Use a structured brief (escalation pack):

```
ESCALATION: [one line]
Severity: P1–P4
Target: Eng / Product / Counsel / Founder

IMPACT — owners affected; workflow; claims/reputation risk; SLA
ISSUE — what shipped vs US-03/04/06/07/09/21
REPRO — Lite vs Plus, remaining quota, kids chip, chat-only vs clip
TRIED — what L0/L1 already said
NEEDED — investigate / fix / withdraw Plus / do not override refuse
```

| From → to | When |
|-----------|------|
| L1 → L2 | Gate behavior unclear; owner demanding a card on bite-risk; banned language in a ticket reply |
| L2 → Eng | Confirmed bug: skip, mid-scare paywall, text-only vision card, meter lie |
| L2 → Product | Pattern: no second scare; “unlimited?” reviews; after-action dominating (A1 hedge becoming the job) |
| Any → Counsel / Founder | Press, name collision, kids-data, K1 decision, policy exception |
| Security (bypass) | Data exposure, child-frame mishandle — do not wait for L2 |

CS **keeps** the owner relationship after an internal escalate. Do not vanish.

**De-escalate** when the owner wanted a diagnosis and the correct answer is the human path — that is not a product bug.

Named kill. CS script, not a pivot:
