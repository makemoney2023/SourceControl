## Editorial principle

Social posts **amplify owned education** — they do not replace site proof. Every pillar maps to a **site route** and, where useful, a **Phase 16 SEO theme**. Education outweighs litter or availability content by roughly **4:1** in the 90-day calendar.

**Sequencing rule (P5 from GTM):** Teach before ask. Do not promote `/inquire` as the primary post CTA until E1–E8 are live on site.

## P1 — Standards & type literacy

**Meaning:** Correct Rottweiler type per FCI Standard No. 147 — proportions, markings, natural tail — without faux-European hype.

| Element | Detail |
|---------|--------|
| **Site home** | `/health#standards` |
| **SEO primary** | ADRK FCI Standard No. 147 Rottweiler |
| **SEO long-tail** | ADRK-aligned vs American Rottweiler type (factual, careful) |
| **Buyer question answered** | "What does ADRK-aligned actually mean?" |
| **Social formats** | Text + link post; carousel "3 things serious buyers check in type" |
| **Sample angle** | "Black with clearly defined rich tan markings — not a color trend. Why the standard matters for structure and health." |
| **CTA pattern** | "Read our standards overview →" → `/health#standards` |
| **Avoid** | "Imported European," "rare bloodline," "XL," "certified by ADRK" (unless Tier 2 verified) |

**Post mix target:** ~25% of 90-day calendar

## P2 — Health transparency

**Meaning:** Responsible programs test hips, elbows, eyes, cardiac, JLPP — results link to registries when verified.

| Element | Detail |
|---------|--------|
| **Site home** | `/health#testing` |
| **SEO primary** | Rottweiler health testing |
| **SEO secondary** | Rottweiler hip elbow OFA testing · JLPP Rottweiler testing |
| **Buyer question answered** | "What health tests should I expect from a Rottweiler breeder?" |
| **Social formats** | Category explainer posts; "what to verify on OFA/CHIC" link posts |
| **Sample angle** | "Hip and elbow evaluations aren't optional extras in serious breeding — they're baseline due diligence. Here's how we think about each category." |
| **CTA pattern** | "See our health testing approach →" → `/health#testing` |
| **Avoid** | "100% healthy," named OFA results until Tier 2, disease-free guarantees |

**Post mix target:** ~30% of 90-day calendar (highest share — compounds trust + SEO)

## P3 — Temperament within bounds

**Meaning:** Good-natured, devoted, biddable, even-tempered — power with responsible ownership, not intimidation marketing.

| Element | Detail |
|---------|--------|
| **Site home** | `/health#temperament` |
| **SEO primary** | Rottweiler temperament breed standard |
| **Buyer question answered** | "Will this breed be stable in a family home?" |
| **Social formats** | FCI temperament quote + plain-English gloss; myth-bust ("steadiness ≠ aggression marketing") |
| **Sample angle** | "A Rottweiler should be self-assured and even-tempered — not a prop for guard-dog fantasy. The FCI standard says good-natured and devoted. That's the temperament we breed toward." |
| **CTA pattern** | "Read temperament within the standard →" → `/health#temperament` |
| **Avoid** | Guard dog, protection dog, weapon, attack, "natural protector" as hero framing |

**Post mix target:** ~20% of 90-day calendar

## P4 — Program & placement process

**Meaning:** Selective, mutual fit; inquiry after research; Package A/B/C without on-site price.

| Element | Detail |
|---------|--------|
| **Site home** | `/health#placement` · `/about` |
| **SEO primary** | Responsible Rottweiler breeder placement process |
| **SEO secondary** | Rottweiler inquiry · interest list |
| **Buyer question answered** | "How does a serious breeder handle inquiry and placement?" |
| **Social formats** | Process explainer; "why we don't list prices on the website" (objection-handling, calm) |
| **Sample angle** | "Inquiry is the start of a conversation about fit — not a checkout. We review every submission individually. Placements are selective and mutual." |
| **CTA pattern (Tier 1)** | "Join our interest list →" → `/inquire` |
| **CTA pattern (Tier 2)** | "Begin your inquiry →" → `/inquire` |
| **Avoid** | Apply now, reserve, limited spots, waitlist urgency, deposit amounts |

**Post mix target:** ~15% of 90-day calendar — never more than 1 process/CTA post per month

## P5 — Dogs & honest program status

**Meaning:** Named breeding stock when verified; honest "coming soon" when not. Competence through transparency, not volume.

| Element | Detail |
|---------|--------|
| **Site home** | `/dogs` · `/about` |
| **SEO primary** | Rottweiler breeding stock |
| **SEO secondary** | Rottweiler sire and dam profiles · health clearances breeding dogs |
| **Buyer question answered** | "Who are the dogs behind this program?" |
| **Tier 1 social** | Program-in-development honesty; link to education while profiles pending |
| **Tier 2 social** | Single-dog profile spotlight when Q6 + health inventory verified — link to `/dogs/[slug]` |
| **Sample angle (Tier 1)** | "Breeding stock profiles are coming soon. Our program is developing — explore our health and education resources to understand our standards in the meantime." |
| **Sample angle (Tier 2)** | "Meet [Dog name] — [role]. Health clearances link to registries on our site when published." |
| **CTA pattern** | "View our dogs →" → `/dogs` |
| **Avoid** | Stock photos, fake names, "available" ribbons, litter drop teasers |

**Post mix target:** ~10% of 90-day calendar — **0% litter/availability** unless operator triggers rare verified announcement

## Pillar → route matrix (quick reference)

```
Social post idea
    │
    ├─ Standards/type? ──────────► /health#standards  (P1)
    ├─ Health tests/categories? ─► /health#testing    (P2)
    ├─ Temperament/myths? ────────► /health#temperament (P3)

```

**Cannibalization guard (from Phase 16):** Social teases one section per post — full detail stays on site. Do not paste entire `/health` sections into Facebook captions.

## Content type mix (searchable vs shareable)

| Type | Pillar fit | Priority |
|------|------------|----------|
| **Searchable education** (answers a specific question) | P1, P2, P3 | Primary — aligns with SEO pillar page |
| **Shareable myth-bust** (counterintuitive calm take) | P3 | Secondary — use sparingly |
| **Process transparency** (meta-content) | P4 | Tertiary — max 1/month |
| **Dog spotlight** | P5 | Q6-gated; Tier 2 only |
| **Litter announcement** | — | **Rare exception** — site publishes first |

## Tier discipline on social

| Tier | Allowed on social | Prohibited |
|------|-------------------|------------|
| **Tier 1** | Breed/standard facts, process posture, honest empty states | Named dogs, OFA results, litter dates, `[LOCATION]` until Q2 |
| **Tier 2** | Operator-verified dog names, registry links, affiliations | Prices, deposit amounts, unverified titles |
| **Tier 3** | **Never** | Puppy prices, fake proof, FOMO, guard-dog marketing |
