**Phase:** 1  
**Status:** draft — ready for C-suite review

**Author:** business-analyst (IC); merged by ceo-strategist  
**Reports to:** ceo-strategist

## Summary

Blacksage Kennels needs a **coherent, trustworthy public presence** so serious Rottweiler buyers can evaluate the program and apply — but the v1 fast-forward sprint failed **holistically** (visual polish, 3D, trust/content, UX/conversion). Phase 1 frames the problem as **strategy and evidence before solutioning**, not a cosmetic website rebuild. This document locks symptoms vs root causes, who hurts, candidate directions, labeled assumptions, scope, and open operator questions so Phase 2–3 can pressure-test rather than repeat the v1 mistake.

## Problem statement

**For** serious Rottweiler buyers seeking German / ADRK-aligned temperament and structure  
**Who** cannot confidently evaluate breeder quality, program standards, or fit from Blacksage's current public presence  
**The** absence of a **coherent, trustworthy channel** (not merely a prettier page)  
**Is a** credibility and conversion gap  
**That** forces buyers to guess, defer, or choose better-packaged alternatives — and wastes operator effort on a channel that failed on every layer  
**Unlike** a cosmetic redesign of the rejected v1 prototype  
**Our restart** must be **strategy-led**: validated customer, site job, evidence, and success criteria **before** brand, web, copy, or build — because v1 failed holistically (visual, 3D, trust/content, UX/conversion), not on a single fixable surface.

### CEO direction (load-bearing)

> Serious buyers can't evaluate or trust Blacksage without a coherent presence. v1 failed holistically; the rebuild must be strategy-led, not cosmetic.

## Symptoms vs root causes

| Symptom (what we observe) | Candidate root cause | Kind |
|---------------------------|----------------------|------|
| Visual polish failed — site feels subpar vs prestige kennel expectation | Design/build sprint ran **without** validated brand strategy, real photography, or acceptance criteria | Inference |
| Scroll-driven 3D failed — did not deliver prestige or conversion | 3D chosen as sprint tactic (soft lock), not validated against site job or buyer needs | Fact + Inference |
| Trust/content failed — serious buyers cannot evaluate the program | No framing of program maturity, geography, or evidence; placeholder copy; risk of invented claims | Fact + Inference |
| UX/conversion failed — apply path does not work for the business | Inquiry destination, form design, and conversion goals undefined before build | Inference |
| Operator rejected entire v1 | Holistic quality bar missed; patching one layer will not fix | Fact |
| Fast-forward skipped phases 0–10 | **Solutioning before framing** — no validated customer, geography, program maturity, success criteria, or site job | Fact (decision log + intake) |
| Soft locks treated as strategy | "Brand + apply equally" and scroll 3D were sprint choices, not Phase 3 outcomes | Fact (decisions.md) |
| Real photography / contact / CRM undocumented | Cannot build authentic trust layer until operator supplies assets and process | Fact |

**Root cause summary (for Phase 2+):** The business problem is **not** "the website needs polish." It is **missing strategic foundation** for what the public presence must accomplish, for whom, with what evidence — which caused v1 to fail across visual, experiential, content, and conversion layers simultaneously.

## Candidate solution directions

*Compare only — **Phase 3 owns strategy selection.** Do not treat any row as decided.*

| Option | Description | Fit vs need | Feasibility now | Risks / notes |
|--------|-------------|-------------|-----------------|---------------|
| **D1 — Strategy-first web hub** | After Phases 2–5: production site as primary credibility + apply channel; 3D/visual TBD by strategy | High if site is primary lever | **Low until strategy/PRD** | Repeats v1 if jumped early; must fix trust/content/UX together |
| **D2 — Trust-first, apply-second** | Lead with evidence, standards-informed education, real media; apply path once program facts exist | High for serious buyers | Medium — needs photography + program maturity answers | Slower conversion if apply de-emphasized |
| **D3 — Apply-first funnel** | Minimal prestige, maximum inquiry capture | Medium — failed in v1 on UX/conversion | Low without trust layer | v1 proved apply without trust fails |
| **D4 — Referral-led + light web** | Word-of-mouth, clubs, trainers; web as digital business card | Medium if program already active locally | Unknown — geography unset | Underserves buyers who research online first |
| **D5 — Brand-first / coming-soon** | Positioning and list-building before litters | Fits if program not yet active | Medium — needs operator Q1 answer | Risk of indefinite "coming soon" without criteria |
| **D6 — Multi-channel package** | Web + social + print/referral kit aligned to one story | High holistically | Low complexity now | Requires more ops than web alone |
| **D7 — Patch v1 cosmetically** | Reskin existing Next.js/R3F app | **Poor** | High technically | **Rejected by framing** — contradicts CEO direction and v1 failure mode E |

**Comparison notes:**

- v1 effectively blended D1 + D3 with unvalidated 3D — and failed on all criteria.  
- D7 is explicitly **out of framing**; operator ordered restart for strategy, not reskin.  
- D2 vs D3 vs D6 tradeoff depends on **site job** (open Q5) and **program maturity** (open Q1) — Phase 3.  
- No option is feasible with authentic trust until **photography** and **non-invented program facts** exist (open Q6, Q1–Q2).

## Recommended framing for Phase 2+

**Not a website rebuild.** Recommended next work:

1. **Phase 2 — Market / evidence:** Pressure-test serious Rottweiler buyer behavior, how competitors present ADRK-aligned programs, and what "trust" requires in this category — using ADRK source and external evidence, not v1 copy.  
2. **Phase 3 — Strategy:** Decide site job (prestige / apply / education / mix) and channel role **before** revisiting 3D, visual system, or apply UX.  
3. **Phase 5 — PRD:** Unambiguous acceptance criteria for **all four v1 failure layers** (visual, experiential/3D if any, trust/content, UX/conversion) tied to operator-supplied facts and media.  
4. **Phases 11–14 → 9:** Only after strategy + PRD; treat v1 as anti-patterns reference, not template.

**Explicit anti-pattern:** Any plan that starts with "fix the hero" or "tweak R3F" without closed site job and trust/content requirements repeats the fast-forward failure mode.
