# Brand reference kit (multi-ref)

FLUX.2-dev / fal multi-reference slots for recurring subjects.

| Slot file (drop photos here) | Role |
|------------------------------|------|
| `identity-01.jpg` … `identity-04.jpg` | Dog/person identity lock (front, 3/4, side, markings) |
| `pose-01.jpg` | Target pose / body language |
| `lighting-01.jpg` | Key light quality / color |
| `environment-01.jpg` | Location / terrain mood |

Named-dog heroes **require** identity refs. Environment/email headers may ship without.
