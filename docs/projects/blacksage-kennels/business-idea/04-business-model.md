**Phase:** 4  
**Status:** draft — ready for C-suite review

**Author:** cfo (merge); ICs: fpa-analyst, product-marketing-manager  
**Venture:** Blacksage Kennels  
**Mode:** explore → economics lock (C-suite gate; phase not marked complete)

## Summary

Blacksage Kennels is a **selective-placement kennel** (transactional service), not SaaS or e-commerce. Revenue is recognized on **qualified pet-home placements**; the website is a **credibility CAPEX/OPEX** asset that earns shortlist survival and qualified inquiry — not a storefront. **Blacksage puppy price is UNKNOWN** — all dollar figures below are **market-context Assumptions** from Phase 2 unless labeled Fact. Category economics look **plausible** at mainstream ethical pricing (~$2k+) with **≥6 placements/year** and a disciplined trust-first (no-3D) web build. Phase 4B fundraising is **skipped** (bootstrapped default A7).

## Unit definition

### Primary unit — Qualified placement

Puppy placed with an approved buyer after screening, contract, and (typically) deposit/waitlist. This is the revenue event.

### Secondary unit — Qualified inquiry

Serious contact after proof review — leading indicator for web ROI, not revenue. Track inquiries/year; model P&L on placements/year.

## Pricing posture

> Blacksage does **not** publish puppy prices or deposit amounts on the public website. Pricing is discussed individually after inquiry review and mutual-fit qualification — consistent with premium ethical breeder norms (**Fact:** 0/8 competitors publish on-site prices). Category bands below are for **financial modeling only**. **Blacksage-specific price band is an operator decision — not documented.**

| Dimension | Posture | Label |
|-----------|---------|-------|
| On-site pricing | None — no "$X", no deposit amount, no "starting at" | Decision (D2, A10) |
| Price discovery | Phone/email after qualification | Inference |
| Site language OK | "Pricing discussed after qualification" / "Investment discussed individually" | Decision |
| Payments on site | **No** — website does not process payments | Decision |

### Monetization sequencing

```
Trust content → Inquiry → Qualification → Price discussion → Deposit (if waitlisted) → Contract → Placement balance
```

## Packaging map

Three packages — **do not collapse**. Live package set depends on **Q1** (program maturity).

| Package | Trigger | Buyer commitment | Payment |
|---------|---------|------------------|---------|
| **A — Interest list** | Q1 = pre-litter / brand-first | Email + brief interest | **None** |
| **B — Waitlist** | Q1 = active + qualified inquiry | Full application + interview | Deposit **after** approval (operator amount) |
| **C — Placement** | Waitlist match + contract | Signed agreement | Deposit credited + balance per contract |

**Value metric:** Approved home fit per selective placement — **not** puppies sold, form volume, or checkout conversion.

### Placement offer anatomy (Package C)

| Component | Design |
|-----------|--------|
| Core deliverable | Selectively placed ADRK-aligned Rottweiler puppy + health docs per operator inventory |
| Value-adds | Real category supports only (socialization narrative, transparency, education, contract) — when operator confirms |
| Guarantee | Contract/return policy when operator provides — no "100% healthy" |
| Scarcity | Natural selectivity only — no FOMO timers |
| Name | "Pet-home placement" — avoid Buy / Reserve / Shop |
| Price + payment | Off-site, post-qualification; deposit credited per operator policy |

## Unit economics

**Formula:** `Contribution = Price (scenario) − Variable COGS (scenario)`

| Price ↓ / COGS → | Low ($350) | Base ($740) | High ($1,410) |
|------------------|------------|-------------|----------------|
| Low ($1,750) | $1,400 | $1,010 | $340 |
| Base ($2,250) | $1,900 | **$1,510** | $840 |
| High ($3,500) | $3,150 | $2,760 | $2,090 |

**Base gross margin:** $1,510 / $2,250 ≈ **67%**.

### After fixed costs

Base kennel fixed $7,200 + Base web amortized ~$1,817 ≈ **$9,017** annual fixed.

| Scenario | Annual contribution | − Fixed | Surplus/(deficit) |
|----------|---------------------|---------|-------------------|
| Bear (3 × $1,010) | $3,030 | $9,017 | **($5,987)** |
| Base (7 × $1,510) | $10,570 | $9,017 | **~$1,553** |
| Bull (14 × $2,760) | $38,640 | $9,017 | **~$29,623** |
| Stress (3 × $340) | $1,020 | $9,017 | **($7,997)** |

### Headline breakeven

**~$9,017 / ($2,250 − $740) ≈ 6.0 placements/year** at base assumptions.

### What must be true

| # | Condition | Label |
|---|-----------|-------|
| C1 | Price ≥ ~$2,000 unless costs stay hobby-scale | Inference |
| C2 | ≥5–6 placements/year at base, **or** lower fixed (home kennel / sweat-equity web) | Assumption |
| C3 | Health/testing cost discipline | Inference |
| C4 | Selective ≠ zero volume — 3 placements at low price is underwater on fixed costs | Inference |
| C5 | Web spend disciplined; no 3D (SD4) | Fact + Inference |
| C6 | Operator may accept day-job / hobby subsidy — not modeled as GAAP P&L | Assumption |

## Waitlist / deposit economics

| Element | Detail | Label |
|---------|--------|-------|
| Wait duration | 6–12+ months common | Fact |
| Deposit amount | **~$500** common (e.g. Dreibergen published policy) | Inference (CI) — **not Blacksage policy** |
| Applied to purchase | Typically credits final price — not incremental revenue | Inference |
| Refundability | Operator-defined; often non-refundable if buyer withdraws | Assumption |

**FP&A rule:** Deposits are a **working-capital tool**, not profit. Example: 10 × $500 = $5,000 float (liability if refundable).

### Trust-first deposit sequencing

1. Trust content on site  
2. Inquiry  
3. Qualification conversation  
4. Written waitlist/deposit terms + contract review  
5. **Then** deposit collected **off-site**

**Site may say:** "A waitlist deposit may be required after application approval. Terms are provided individually."  
**Site must not:** collect deposits or show a dollar amount until operator locks policy.

### Risks

| Risk | Mitigation |
|------|------------|
| Deposits before Q1 capacity clear | Interest list (Package A) until active program |
| Too many deposits vs litter size | Selective list management; honest capacity |
| Deposit hesitation from trust gap | D2 web before deposit CTAs |

## Website cost vs value

### Cost of status quo (v1 hollow)

| Cost | Mechanism | Label |
|------|-----------|-------|
| Shortlist elimination | No named dogs/tests → removed from 3–8 site scan | Fact (buyer journey) |
| Referrer silence | URL not shareable | Inference |
| Bad lead load | Apply-first without proof | Inference (v1 / D3) |
| Cosmetic patch (D7) | Repeats sunk cost without trust ROI | Decision |

**Lost-revenue proxy (Assumption):** If hollow site blocks 2–4 qualified inquiries/year converting at 25–50% to $2,250 placements → **~$1,125–$4,500/year** opportunity cost — on the order of base Year-1 web spend.

### Investment recommendation

| Metric | Value |
|--------|-------|
| Recommended Year-1 all-in | **~$3k–$5.5k** Base; ceiling **≤$8k** (or sweat equity) |
| Payback @ $1,510 contribution | **~3.6 incremental placements** |
| 3D | **Do not fund** (SD4) — redirect to photography + health content |

### Proceed conditions (web)

1. Real photography / staged launch tiers (Q6) — no hollow rebuild  
2. Budget ≤$8k Year-1 or explicit sweat equity  
3. No 3D in v1  
4. Inquiry destination + owner defined (Q7)  
5. Success = qualified inquiry quality + referrer shareability (M5), not traffic alone

## Sensitivity

| Variable | Direction that breaks model |
|----------|----------------------------|
| Placements/year | **<5** at mainstream price + non-hobby fixed (**primary driver**) |
| Price | Low band ($1,500–$1,750) + High COGS |
| Kennel fixed | $15k+ without premium price or second income |
| Web spend | Large spend before media ready — delayed ROI |
| Deposit UX | Waitlist/deposit live without Q1 capacity — reputational + refund liability |

**Does not break alone:** hosting (~$250/yr), organic CAC, moderate $3k–$5k web if ≥1 incremental placement/year.
