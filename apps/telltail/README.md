# telltail — scoped Phase 9 eval harness

Not an MVP. Not an App Store build. Not a branded UI.

This folder holds a **CLI kid-vs-dog eval** only: three Wikimedia stills and one Lite cheap-model vision call per still.

```
python3 eval/kid_vs_dog.py
```

Default model: `gemini-3.5-flash-lite` (the Lite cheap-model that answered this key). `gemini-2.5-flash-lite` 404s for new users.

Do not treat this directory as a verified Next.js app.
